# Tigo brand images

These unmodified PNG icons and logos are sourced from the
[Home Assistant brands repository](https://github.com/home-assistant/brands/tree/master/custom_integrations/tigo).

- `icon.png`: 256 × 256
- `icon@2x.png`: 512 × 512
- `logo.png`: 594 × 256
- `logo@2x.png`: 1188 × 512

The Tigo name, logo, and leaf mark belong to Tigo Energy. They identify the
hardware supported by this community integration; PyTap is not an official
Tigo integration. The integration's MIT license does not grant rights to these
trademarks.

Home Assistant automatically serves this folder through its brands API. Its
native fallback uses these same images for dark variants when a dedicated
dark-theme image is not present. No manifest branding option, CDN registration,
or custom HTTP view is required.
